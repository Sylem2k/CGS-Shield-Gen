# CGS Shield Generator — V3.6 hum and inside-visibility repair
This change uses the existing `Sounds/War-Small-Gen.wav` and `Props_Shield_Gen_Hum.acp`. The original ACP referenced three missing `Sampes/Props_GeneratorMilitary_*.wav` files. The ACP samples now point to the existing mod WAV; the unused TurnOn and TurnOff sound events are temporary audio placeholders.
The base generator prefab has a `SimpleSoundComponent`, and `CGS_ShieldGeneratorComponent.c` plays `SOUND_GENERATOR_LP` on each client whenever the replicated power state is STARTING (1), ON (2), or STOPPING (3). It terminates once OFF (0), destroyed, or deleted. It does not use a looping RPC.
## Inside visibility: current source is newer than compiled .xob
The repository already contains the V3.5 FBX with inward-facing faces: the polygon-vertex index array grew from 1984 in V3.4 to 3968 in V3.5. However, the actual visual prefab loads `{F60A3CDE13254462}Assets/Shield/CGS_Shield_Bubble.xob`, not FBX directly. The checked-in .xob was not rebuilt with those inner-facing faces.
**Workbench required:**
1. Back up `Assets/Shield/CGS_Shield_Bubble.xob` and its `.meta`.
2. In Resource Browser, find `Assets/Shield/CGS_Shield_Bubble.fbx` and explicitly **Reimport** it, targeting the existing `CGS_Shield_Bubble.xob`; keep its existing resource GUID `{F60A3CDE13254462}`.
3. Ensure the imported mesh includes the inside polygons; don't merely change the FBX or delete its `.meta`.
4. In `Prefabs/Shields/CGS_ShieldBubble.et`, check MeshObject still points to that rebuilt .xob and uses `Assets/Shield/Data/CGS_Shield_Bubble.emat`. There should be **one** visual entity and **one** MeshObject.
5. Spawn a **new** generator, activate it, walk through the sphere, and confirm blue surface is visible from both sides. If not, inspect the reimport log and the generated mesh; the material may need a two-sided rendering variant.
Compiled .xob resources cannot be regenerated by editing Enfusion scripts. This project does not bundle a Workbench-rebuilt .xob; do not claim the inside rendering issue is validated until it has been reimported and tested.
